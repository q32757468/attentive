# Support

Please report bugs and feature requests in the
[Attentive GitHub issue tracker](https://github.com/q32757468/attentive/issues).

When reporting an integration problem, include:

- VS Code version and operating system
- Whether the window is local, Remote SSH, WSL, or a development container
- Attentive CLI version and the command that was run
- The output of **Attentive: Show VS Code Integration Status**
- Whether restarting the integrated terminal resolved the problem

Do not include callback URIs, IPC endpoint values, access tokens, workspace
secrets, or other private data in an issue.

Before opening an issue, update VS Code and the Attentive CLI, reload the VS
Code window, and create a fresh integrated terminal.
